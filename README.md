**Student:** Your Full Name

## Description
A multi-page website that demonstrates HTML forms, HTML5 validation, Bootstrap form
components and Bootstrap validation feedback. A shared navbar links all pages.

| Page | Content |
| --- | --- |
| `index.html` | Home page with links to all tasks |
| `task0-basic-form.html` | Simple contact form (name, email, message) with labels |
| `task1-html5-validation.html` | Same form with `required`, `type`, `minlength`, `maxlength`, `pattern` |
| `task2-bootstrap-form.html` | Bootstrap-styled form using the grid, placeholders and helper text |
| `task3-bootstrap-validation.html` | `is-valid` / `is-invalid` classes with feedback messages (`task3.js`) |
| `task4-registration.html` | Responsive registration form with full validation (`task4.js`) |

## How to run
1. Clone the repository.
2. Open `index.html` in a browser (no build step needed). Bootstrap 5.3 is loaded from a CDN, so an internet connection is required.
